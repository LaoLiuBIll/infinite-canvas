# 待测试

- 配音工作台使用实际配置的 TTS 渠道生成中文口播，核对音色、语速和下载格式。
- 资产中心一期上线验收。批量导入后按完整款号筛选，插入画布，移入回收站后重开画布并恢复，检查生成结果保存和批量下载。
- 资产管理页验收。新增空分类后刷新，新增资产并归类，改名后查找，删除分类后检查资产转为未分类，再验证资产回收与恢复。
- 后台「用户内容」验收。分别查看管理员和普通用户的云端素材、成果、资产，核对账号筛选、媒体详情及非管理员权限。
- 后台用户管理列表点击「查看内容」，核对素材、成果、资产均按该账号筛选，刷新后筛选仍有效。
